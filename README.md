📝 File Editor & Summariser
File Editor is a powerful, whimsical, and developer-friendly web application designed to handle all your document manipulation needs in one place. Built with a unique "Programming Treehouse" aesthetic, it combines robust backend functionality with a creative, intuitive user interface.

🚀 Features
This repository provides a comprehensive suite of tools for managing PDFs and various document types:

🔗 Merge Files: Seamlessly combine multiple files (PDF, Word, PPT, or Images) into a single document.

📥 Insert File: Precisely insert a specific document into another at a designated page position.

✂️ Split PDF: Break down large PDF documents into smaller, manageable files based on page ranges.

🔄 Rotate PDF: Correct the orientation of your documents with custom rotation angles.

🗑️ Remove Pages: Clean up your files by stripping away unnecessary pages or sections.

📊 Summarise PDF: Use AI-driven logic to generate concise summaries of long documents in various output formats.

🔄 Convert PDF: High-fidelity conversion from PDF to editable Word (.docx) or PowerPoint (.pptx) formats.

🎨 Design Philosophy
The interface is designed to make document management feel less like a chore and more like a craft.

Themed UI: A "Tech Treehouse" background featuring circuit-board traces and developer mascots.

Tactile Elements: Navigation modules featuring hand-carved wood headers and sculpted input frames.

Glassmorphism: Modern, semi-transparent control panels that blend perfectly with the whimsical environment.
